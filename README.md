Weather History Analysis | Power BI

Project Overview

This project analyzes historical weather data using Microsoft Power BI.
An interactive dashboard was created to visualize weather patterns,
trends, and comparisons across different years.

Tools & Technologies

- Microsoft Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

Key Analysis

The dashboard provides insights into:

- Humidity trends
- Atmospheric pressure
- Visibility
- Apparent temperature
- Year-wise weather comparisons

Project Objective

The objective of this project is to transform historical weather data
into meaningful visual insights using Power BI, making it easier to
identify patterns and understand changes in weather conditions.

Dashboard

The Power BI dashboard provides an interactive visual representation
of the analyzed weather data.
